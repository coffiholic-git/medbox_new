# intentionally NOT installed by default:
#   - They are imported lazily inside PaddleOCREngine.__init__, so nothing

#   - If they're missing, services/ocr_service.py already falls back to
#     Tesseract automatically (see perception/pipeline.py _default_primary_engine),
